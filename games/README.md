# games

Drop your exported PGN files here (from chess.com, lichess, etc.) and import
them with:

```
Tempo> import games
```

This imports every `.pgn` file in this folder in one go. You can also import
a single file directly:

```
Tempo> import games/my_games.pgn
```

Later, this folder can also serve as the drop point for games fetched
automatically from chess.com/lichess.
